# Contributing to CORE Echo

Thanks for your interest in contributing to CORE Echo.

## Getting started

1. Fork the repository.
2. Clone your fork.
3. Create a branch for your change.
4. Make your changes.
5. Test the project in HISE.
6. Commit your changes.
7. Push your branch.
8. Open a pull request.

## Branch naming

Examples:

- `fix/preset-browser`
- `fix/delay-sync`
- `feature/new-presets`
- `docs/build-instructions`

## Pull requests

Please include:

- What you changed
- Why you changed it
- How you tested it
- Screenshots for interface changes

## Bug reports

Include:

- CORE Echo version
- Operating system
- DAW
- Steps to reproduce
- Expected behavior
- Actual behavior
