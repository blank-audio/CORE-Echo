# CORE Echo

CORE Echo is a free and open-source delay and reverb plugin from blank audio.

## Features

- Delay and reverb processing
- Tempo-synced delay
- Dry / wet balance control
- Built-in preset library

## Formats

- VST3

## Platforms

- Windows

## Installation

Download the latest installer from the Releases page and run the installer.
